# ProLoop project page

Static, anonymous research website. Layout inspired by RoboInter; content, results, and figures come from the supplied September 2026 ProLoop manuscript. Blue, coral, and sage accents mirror its progress-state diagrams.

GitHub Pages serves `index.html` directly (`.nojekyll`). No build dependencies. Preview with a static HTTP server. Styles and interactions live in `assets/style.css` and `assets/site.js`; the paper is `assets/ProLoop.pdf`.

Results reproduce Tables I–IV. The performance table shows overall SR/PR/GA and Easy/Hard SR; consult the paper for split PR. Improvements in the overview are percentage-point gains against Reason-Only with Qwen3-14B. Do not interpret these as relative percentage gains. No experiment videos or implementation code are claimed to be released.
