# ProLoop project page

Static, anonymous research website. Layout inspired by RoboInter; content, results, and figures come from the supplied September 2026 ProLoop manuscript. Blue, coral, and sage accents mirror its progress-state diagrams.

GitHub Pages serves `index.html` directly (`.nojekyll`). No build dependencies. Preview with a static HTTP server. Styles and interactions live in `assets/style.css` and `assets/site.js`; the paper is `assets/ProLoop.pdf`.

Website prose, headings, and captions are verbatim excerpts from the supplied manuscript, with PDF line wrapping normalized. Only interface labels are website-specific. Tables I and IV are displayed; Tables II and III are discussed using original manuscript sentences. Table I includes overall SR/PR/GA and Easy/Hard SR/PR for both backbones. Do not introduce paraphrases or independently rewritten numerical claims.

The four displayed figures are rendered at 220 dpi from the separately supplied Proloopfig2(1).pdf, Proloopfig3.pdf, Proloopfig4.pdf, and Proloopfig5(1).pdf. Only blank page margins are cropped. Figure 1 was not previously displayed and has not been added. The downloadable manuscript is unchanged.
