# ProLoop project page

Static, anonymous research website. Layout inspired by RoboInter; content, results, and figures come from the supplied September 2026 ProLoop manuscript. Blue, coral, and sage accents mirror its progress-state diagrams.

GitHub Pages serves `index.html` directly (`.nojekyll`). No build dependencies. Preview with a static HTTP server. Styles and interactions live in `assets/style.css` and `assets/site.js`; the paper is `assets/ProLoop.pdf`.

The September 22 update uses the supplied Proloop(2).pdf. Abstract, experiment prose and figure captions follow that manuscript, with PDF line wrapping normalized. The four Methodology cards are concise, manuscript-grounded summaries requested by the authors. Tables I and IV are displayed; Tables II and III are discussed using manuscript sentences. Table I includes overall SR/PR/GA and Easy/Hard SR/PR for both backbones. Table IV includes w/o Summary and w/o Relation Head.

The five displayed figures are vector SVGs converted from the supplied Proloopfig1.pdf, Proloopfig2.pdf, Proloopfig3.pdf, Proloopfig4(1).pdf, and Proloopfig5.pdf. The hero uses Fig. 1; Methodology contains Fig. 2 then Fig. 3; Experiments and Real-World Robotic Experiment use Fig. 4 and Fig. 5. SVG viewports exclude only blank page margins. Clicking a figure opens the interactive zoom/pan viewer, with an unchanged original PDF available through its PDF link. The downloadable manuscript is an unchanged copy of Proloop(2).pdf.

The original supplementary MP4 (153,857,242 bytes) is stored as ProLoop.mp4 in the supplementary-video-2026-09 GitHub release because it exceeds GitHub's ordinary Git file-size limit. The video player follows Fig. 1 and provides playback controls and an original-file download link. The MP4 is not recompressed.
